# 메타 규정 체크리스트

2026-11-03에 메타 투명성 센터와 인스타그램 고객 센터의 원문을 읽고 정리했다. 부업, AI 툴, 자동화, 판매, 자료 배포 콘텐츠에 직접 걸리는 규정만 담았다. 나머지 규정은 [other-rules.md](other-rules.md)에 있다.

규정은 자주 바뀐다. 판단이 갈리면 원문을 다시 연다. 주소는 `https://transparency.meta.com/policies/community-standards/<슬러그>/`이고, 내장 브라우저로 연다. WebFetch는 긴 규정을 잘라먹고, `/ko-kr/`이 붙은 주소는 404가 날 수 있다.

각 항목의 🔴🟠🟡는 기본값이다. 문맥을 보고 조정한다.

## 1. 제재가 작동하는 방식

- **삭제 + 스트라이크**: 커뮤니티 규정 위반. 심각성, 공유된 상황, 게시 시점에 따라 적용되고 1년 뒤 만료된다. FB와 IG의 위반 횟수는 합산된다.
- **오래된 게시물**: 게시 후 90일(심각한 위반은 4년)이 지난 콘텐츠는 삭제돼도 스트라이크로 세지 않는다.
- **세지 않는 경우**: 자기 금융 정보를 공유해 사기 방지 목적으로 삭제된 경우, 맥락이 더 있는 경우.
- **계정 비활성화**: 반복된 경고와 제한 뒤에도 위반이 이어질 때. 횟수는 공개되지 않았다. 아동 성착취 등 심각한 위반은 한 번으로도 비활성화된다.
- **추천 제외**: 규정 위반이 아니어도 추천 가이드라인에 걸리면 비팔로워에게 나가지 않는다. **최근 커뮤니티 규정을 위반한 계정은 계정 자체가 추천 대상에서 빠질 수 있다.**
- **이의 제기**: 받아들여지면 콘텐츠가 복구되고 위반 횟수도 삭제된다.
- 횟수별 제재표(1회 경고, 7회 1일 제한 …)는 **Facebook 기능 제한** 기준이다. 인스타그램에 그대로 적용된다고 말하지 않는다.

## 2. 돈과 결과의 약속 (금지된 상업적 행위, `prohibited-commercial-practices`)

규정은 사기를 겨냥하지만 진짜 경험담도 같은 형태면 자동 시스템에 걸릴 수 있다. 조항마다 적용 범위가 다르니 근거를 쓸 때 구분한다.

| 점검 | 기본 등급 | 예 |
|---|---|---|
| **일확천금**: 불분명하거나 최소한의 노력으로 비현실적인 금전 보상 기회 제안 | 🔴 [규정 명시] | "버튼 하나로 월 천" |
| **채용**: 급여를 미리 약속한 일자리, 보장된 일자리 | 🔴 [규정 명시] | "이 일 하면 일당 보장" |
| **채용**: 고용주·직무 정보 없이 채용만 언급 | 🔴 [규정 명시] | "재택 알바 모집, 댓글 주세요" |
| **채용**: 직무상 불가능한 재택 제안, 작업 승인 전 수수료 요구 | 🔴 [규정 명시] | 교육비를 내야 일감을 받는 구조 |
| **투자 기회**: 수익 보장·무위험 | 🔴 [규정 명시] | "손해 볼 일이 없습니다" |
| **투자 기회**: 모집 인원에 따라 수익이 달라짐 | 🔴 [규정 명시] | 추천인 수당 |
| **투자 기회**: 과거 성과를 내세워 비슷한 결과를 기대하게 함 | 🔴 [규정 명시] | "제 수익률 보세요, 여러분도" |
| **투자 기회**: 24시간 내 빠른 수익, 머니 플립 | 🔴 [규정 명시] | "오늘 넣으면 내일 두 배" |
| 부업·판매 제안에 위 투자 조항의 논리 적용 (과거 수입을 내세워 같은 결과 암시) | 🔴 [해석] | "저는 3천 벌었어요, 여러분도" |
| 정부 보조금으로 허위 수익 제안 | 🔴 [규정 명시] | "이 지원금만 받으면" |
| 상업적 이익을 위한 기만 전략 전반 | 🔴 [규정 명시] | 지어낸 사례, 가짜 마감 |
| 유명인·브랜드 이름이나 이미지로 낚는 사기 | 🔴 [규정 명시] | 유명인이 추천한 것처럼 표시 |
| 대출·보험·부채 탕감·신용 회복 약속, 사전 수수료 | 🔴 [규정 명시] | 해당 주제가 나오면 원문 확인 |

**판매자 피드백 조항**: 부정적 피드백이 패턴으로 쌓이면 경고 뒤 계정 제한이나 비활성화까지 갈 수 있다. 강의·전자책·과일 판매에 해당한다. 🟠 [규정 명시]

- 오해의 소지가 있거나 불합리한 가격, 미배송, 광고와 크게 다른 품질
- 사전 고지 없는 청구, 명시한 환불 정책 위반, 약관 공개 없는 구독 등록

주의할 점:
- "하루 30분", "버튼 하나" 같은 훅은 **작업 편의를 말할 때는 괜찮다.** 수입이나 결과를 암시하는 문장과 묶이면 일확천금 조항에 걸린다. [해석] 부업·판매 영상의 제목에 쓰면 금액이 없어도 수입 암시로 읽힐 수 있으므로 🟡로 표시한다.
- "퇴사했다", "인생이 바뀌었다"는 돈 단어가 없어도 수입을 암시할 수 있다. [해석]
- 사기를 비판·교육하거나 뉴스로 전하는 콘텐츠는 허용된다. 민감한 정보를 드러내거나 그 행위를 홍보하면 안 된다. [규정 명시]

## 3. 수익 인증 캡처 (개인정보 침해, `privacy-violations`)

이 규정은 **게시자 본인의 정보도 포함한다.** 자기 금융 정보로 삭제되면 스트라이크로 세지 않을 수 있지만, 콘텐츠는 삭제된다.

| 점검 | 기본 등급 |
|---|---|
| 통장·정산 내역 등 비공개 금융 기록이나 명세서 (본인 것 포함) | 🔴 [규정 명시] |
| 계좌번호, 카드 정보, 결제 로그인 정보 | 🔴 [규정 명시] |
| 사업체의 비공개 금융 기록 (그 사업체가 직접 공유했거나 공시 의무인 경우는 예외) | 🟡 [규정 명시] |
| 고객·타인의 개인 연락처, 비공개 집 주소 (DM·주문 캡처, 송장) | 🔴 [규정 명시] |
| 타인의 신분증, 주민등록번호 등 식별 정보 | 🔴 [규정 명시] |
| 공식 기록이 출처인 타인의 건강 정보 | 🔴 [규정 명시] |
| 후기 캡처에 이름·프로필 사진이 보임 | 🟡 [해석] 가리거나 동의를 받는다 |
| 영상 속 인물의 삭제 신고 (미국 외 성인은 관련법이 권리를 줄 때) | 🟡 [규정 명시] |

## 4. 참여 조건과 스팸 (`spam`, 추천 가이드라인, 수익화 정책)

| 점검 | 기본 등급 |
|---|---|
| 자료를 받으려면 좋아요·공유·**팔로우**를 하도록 요구 | 🔴 [규정 명시] |
| 자료를 받으려면 **댓글**을 달도록 요구 | 🔴 [해석+경험] 규정은 "좋아요, 공유, 팔로우 또는 기타 공개 참여 형식"이라고 쓰고, 참여를 금전적 가치와 교환하는 것도 금지한다. 댓글을 직접 명시하지는 않는다. 같은 형식의 계정이 참여 구매·판매 사유로 삭제 알림을 받은 사례가 있으나, 원인으로 확인되지는 않았다 |
| 좋아요·댓글·링크 클릭으로 반응을 유도하는 콘텐츠 | 🟠 [규정 명시] 수익화 불가(수익화 정책), 추천 제외 대상(크리에이터 FAQ) |
| 참여 대가로 현금·경품·금전적 가치를 제공 | 🔴 [규정 명시] |
| 콘테스트·경품 홍보 | 🟠 [규정 명시] 추천 제외 대상 |
| 약속한 것과 크게 다른 내용으로 연결되는 링크 | 🔴 [규정 명시] |
| 도메인이 바뀌는 리디렉션, 팝업·이탈 방해가 있는 랜딩 페이지 | 🔴 [규정 명시] |
| 자료를 준다더니 결제·긴 가입을 요구 | 🟠 [해석] |
| 수동·자동으로 매우 빈번하게 게시·참여 (대량 자동 댓글·DM 포함) | 🟡 [해석] 규정에 "자동"이 있지만 DM은 직접 언급되지 않는다 |
| 같은 영상 반복 게시 | 🟠 [규정 명시] 빈도가 낮아도 제한될 수 있음 |
| 계정·참여(팔로워, 좋아요)를 사고팔기, 콘텐츠를 금전과 교환 | 🔴 [규정 명시] |
| 인위적 참여를 위한 조직적 댓글 네트워크, 본문과 무관한 장문 캡션 | 🟠 [규정 명시] 추천 제외 |
| 요청받지 않은 많은 사람에게 메시지 보내기 (콜드 DM 대량 발송, `bullying-harassment`) | 🔴 [규정 명시] 원치 않는 접촉 |
| 조회수·팔로워를 늘려 주는 대행이나 서비스를 홍보 | 🟡 [해석] 참여 판매로 읽힐 수 있다. 실제로 참여를 사고팔면 🔴 [규정 명시]. 콘텐츠 기획·제작 업무라고 구체적으로 쓴다 |
| 계정이 사라져 새 계정으로 다시 시작한다는 내용 | 🟡 사라진 이유를 먼저 확인한다. 메타가 비활성화한 계정의 소유자가 만든 새 계정은 문구와 관계없이 제한·비활성화될 수 있다 [규정 명시]. 이 사실을 숨기는 수정은 하지 않고 [takedown.md](takedown.md)를 읽는다 |

수정 방향: 자료를 조건 없이 프로필 링크에 두고 "프로필 링크에 있습니다"라고 한 문장으로 안내한다. 지금 누르라고 재촉하지 않는다. 문서는 안내와 클릭 유도의 경계를 정하지 않았으므로 이 기준은 [해석]이다. 대안을 쓰면 댓글 수는 줄 수 있으니, 트레이드오프를 함께 알린다. 조언이나 추천을 구하는 진짜 질문은 메타가 강등하지 않으려고 조정한 유형이다(Facebook 문서 기준). 댓글을 받고 싶으면 자료와 분리해 질문한다.

## 5. 화면에 넣는 가짜 요소 (`spam`)

| 점검 | 기본 등급 |
|---|---|
| 실제로 동작하지 않는 재생·좋아요 버튼, 설문, 기부 캠페인을 넣어 링크로 유도 | 🔴 [규정 명시] |
| 버튼 모양 그래픽, 가짜 댓글 UI (링크 유도 없이 연출로만 사용) | 🟡 [해석] |
| 유명 브랜드·사이트로 착각할 만한 이름이나 도메인 | 🔴 [규정 명시] |
| 인스타그램 로고를 썸네일의 중심으로 쓰거나, 색을 바꾸거나, 애니메이션을 넣음 (`meta-intellectual-property`) | 🔴 [규정 명시] 게시하지 말라는 항목 |
| 하트 버튼 같은 UI 요소를 따로 떼어 쓰거나, 효과를 넣거나, 기기 화면 없이 보여줌 (`meta-intellectual-property`) | 🔴 [규정 명시] 문서는 "어떤 제품이든"이라고 쓴다. Meta 제품 화면으로 읽는다 [해석] |
| "인스타 공식", "메타 인증"처럼 Meta의 보증을 암시 (`meta-intellectual-property`) | 🔴 [규정 명시] |

앱 화면을 움직이는 편집은 위 UI 항목을 확인한다. 인스타그램 화면은 폰이나 PC 안에 그대로 보여주는 쪽이 안전하다. [해석]

## 6. AI로 만든 콘텐츠 (`misinformation`, AI 레이블 도움말, 추천 가이드라인)

| 점검 | 기본 등급 |
|---|---|
| **AI로 만든 사실적인 보이스오버·음성이 든 릴스**, 사실적인 AI 영상, AI 보컬 노래에 레이블 없음 | 🟠 [규정 명시] 레이블 필수, 없으면 페널티 가능. "사실적인 보이스오버 내레이션이 포함된 릴스"가 도움말의 예시다 |
| 실제 사람처럼 보이는 AI 인물이 눈에 띄게 나오는 콘텐츠를 반복 공유 | 🟠 [규정 명시] AI 생성 프로필 레이블이 없으면 계정 추천 제외 |
| 공적 사안을 사실처럼 꾸민 합성물 | 🟠 [규정 명시] 정보성 레이블이 전면에 붙을 수 있음. 다른 규정 위반이면 삭제 |
| AI 이미지, 만화풍 AI 영상 | 표시 의무 없음 [규정 명시]. 메타가 감지하면 레이블이 붙을 수 있다 |
| 길이 줄이기, 음악 추가 등 일반 편집 | 메타는 대개 해롭지 않다고 본다 [규정 명시] |

레이블 다는 법: 릴스를 만들 때 **AI 레이블 추가** 토글을 켠다. 나레이션에서 "AI 목소리입니다"라고 말하는 것은 이 표시를 대신하지 않는다. [해석]

## 11. 카드뉴스

슬라이드마다 위 항목을 똑같이 적용한다. 이미지 속 글자도 캡션과 같은 기준으로 본다. [해석] 카드뉴스에서 특히 자주 나오는 형태는 아래와 같다.

| 점검 | 기본 등급 |
|---|---|
| 뒷장을 보려면 좋아요·공유·팔로우를 하라는 문구 ("3번째 방법은 팔로우한 분만") | 🔴 [규정 명시] |
| 자료를 받으려면 저장·댓글을 하라는 문구 | 🔴 [해석+경험] 공개 참여가 아닌 저장은 🟠 [해석] |
| "저장해두세요"처럼 조건 없이 권하는 말 | 걸리지 않음. 조건이나 대가를 걸 때만 위 항목이다 [해석] |
| 표지의 수익 약속 ("월 300 버는 부업 3가지") | 🔴 2절 기준. 돈 단어는 [경험] |
| 수익 인증, 정산, 후기 캡처 슬라이드 | 🔴 3절 기준 |
| 후기 캡처의 전화번호·집 주소 | 🔴 [규정 명시] |
| 후기 캡처의 이름, 프로필 사진 | 🟡 [해석] 가리거나 동의를 받는다 |
| 동작하지 않는 재생·좋아요·다음 버튼을 그려 링크로 유도 | 🔴 5절 기준 |
| 인스타 로고를 표지 중심에 쓰거나 색을 바꿈, 하트 버튼만 떼어 씀 | 🔴 5절 기준 |
| 기사, 다른 계정 게시물, 책 페이지를 캡처해 슬라이드로 사용 | 🔴 권리자 신고 시 삭제 [규정 명시]. 위주로 쓰면 🟠 추천 제외 [규정 명시] |
| 남의 사진·일러스트 무단 사용, 다른 앱 워터마크 | 7절 기준 |
| 기사처럼 꾸민 가짜 헤드라인, 지어낸 통계 | 🔴 [규정 명시] 상업적 이익을 위한 기만 |
| 사실적인 AI 이미지 | 표시 의무 없음 [규정 명시]. 메타가 감지하면 레이블이 붙을 수 있다 |
| 건강·다이어트 전후 비교 슬라이드 | 🟠 10절 기준 |
| 슬라이드와 무관한 장문 캡션 | 🟠 [규정 명시] 추천 제외 |

인스타그램이 사진과 캐러셀까지 비원본 콘텐츠의 추천 제외를 넓혔다는 2026년 보도가 있지만, 메타 공식 공지는 확인하지 못했다. 다른 계정 콘텐츠를 모은 카드뉴스는 직접 쓴 설명을 더하도록 권한다. [해석]

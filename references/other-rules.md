# 메타 규정 참고: 그 밖의 주제

2026-11-03에 읽은 페이지 기준이며, 원문은 `https://transparency.meta.com/policies/community-standards/<슬러그>/`에 있다.

- 🔴 문서가 삭제 대상이나 게시 불가로 적은 항목. 예외에 들면 내려간다.
- 🟠 18세 이상 제한, 경고 화면, 민감 레이블이 붙는 항목.
- 🟡 문서가 "추가 정보/컨텍스트 필요"로 분류했거나 메타의 맥락 판단에 달린 항목.

## 아동 관련 내용을 보면 먼저 멈춘다

아동(실제·허구 모두)을 성적으로 표현하거나 대상화한 듯한 내용이 있으면 점검을 멈춘다. 수정안, 완곡한 표현, 대체 문구를 쓰지 않고, 내용을 결과에 옮겨 적거나 자세히 설명하지 않는다. 판정은 "올리지 마세요"로 하고, 그 부분을 통째로 없애라고만 안내한다. 근거는 `child-sexual-exploitation-abuse-nudity` 절에 있다.

## 따돌림 및 괴롭힘 (`bullying-harassment`)

대상부터 가른다. 공인은 주·국가 공무원, 공직 후보, 소셜 미디어 팬·팔로워 100만 이상, 뉴스에 자주 보도되는 사람이다. 그 밖의 사람은 개인으로 더 강하게 보호하고, 18세 미만은 신분과 상관없이 더 강하게 보호한다. "제한된 범위의 공인"은 유명세가 본인 활동에 한정되거나 비자발적으로 유명해진 사람 등이다.

| 점검 | 기본 등급 |
|---|---|
| 모든 사람: 반복 연락, 요청 없이 많은 사람에게 보내는 원치 않는 접촉 (예시: 콜드 DM 대량 발송) | 🔴 [규정 명시] |
| 모든 사람: 자해·자살 요구, 괴롭힘 참여 요구 (예시: "이 계정 가서 한마디씩 해주세요") | 🔴 [규정 명시] |
| 모든 사람: 비공개 전화번호·주소·이메일·의료 기록 공개 협박, 폭력적 비극이 없었다거나 피해자가 연기한다는 주장, 성폭력 피해 경험을 이용한 공격, 성적 비하 이미지·용어 | 🔴 [규정 명시] |
| 사망 기원, 병에 걸리라는 말, 죽음·건강 상태 조롱, 성병 주장, 외모가 열등하다는 언급 | 🔴 [규정 명시] 성인 공인은 "의도적으로 노출"된 경우로 좁혀진다. 태그처럼 직접 겨냥한 경우로 읽는다 [해석] |
| 외모나 성격으로 사람 순위 매기기 (예시: 실제 인물 외모 티어표) | 🔴 [규정 명시] 미성년자, 성인, 제한된 범위의 공인 대상 (미성년 공인은 의도적 노출 시) |
| 코·귀 같은 신체 특성에 동그라미·강조를 넣어 부정적 관심을 끌기 (예시: 특정인 사진 위 동그라미 자막) | 🔴 [규정 명시] 대상 범위 위와 같음 |
| 사람을 열등하게 여겨지는 동물·세균·쓰레기에 비유, 신체적 괴롭힘을 당하는 사람을 비하 (격투 스포츠 제외) | 🔴 [규정 명시] 대상 범위 위와 같음 |
| 상대방을 괴롭히는 장난 (예시: 친구·직원을 골탕 먹이는 몰래카메라), 다른 성인을 성적 대상화, 성적 행위 관련 주장 (비동의 범죄 혐의 제기 제외) | 🔴 [규정 명시] 미성년자, 성인, 제한된 범위의 공인 대상 |
| 대상을 특정한 욕설, 경멸·혐오 표현, 연애 관계·성적 지향·성 정체성 주장 | 🔴 [규정 명시] 미성년자, 미성년 비자발적 공인, 성인(본인 신고 필요) 대상 |
| 성격·능력에 대한 부정적 주장 (예시: 실명으로 "그 강사 무능하다"). 성인에 대한 범죄 혐의 제기와 비즈니스 리뷰는 제외 | 🔴 [규정 명시] 대상 범위 위와 같음 |
| 원치 않는 이미지 조작, 외모로 다른 사람과 비교, 종교 정체성 주장, 신체에 대한 중립적·긍정적 묘사 | 🔴 [규정 명시] 당사자 신고가 있어야 적용 |
| 미성년 개인: 범죄·불법 행위 주장, 신체적 괴롭힘 영상 공유(상황 불문) | 🔴 [규정 명시] |
| 공인을 성적 대상화, 태그 등으로 대상을 직접 겨냥한 콘텐츠 | 🟡 [규정 명시] 대상이나 공식 대리인이 원치 않는다고 확인하면 삭제 |
| 오프라인 위험이 높은 사람(미성년자, 폭력 사건 피해자, 인권 옹호자 등)을 겨냥한 집단 괴롭힘 | 🟡 [규정 명시] |

예외: 괴롭힘에 항의하거나 주의를 환기하려는 것이 명백한 공유는 허용된다. 공인에 대한 비판적 해설과 토론도 허용된다. 1900년 이전 사망자와 위험 단체로 지정된 조직의 일원에게는 이 규정이 적용되지 않는다. 메시지·페이지·그룹·이벤트에도 같은 보호가 적용된다. 이 페이지의 "성인"은 공인과 따로 쓰였으므로 공인이 아닌 성인으로 읽는다 [해석]. 2등급 대상 목록에 일반 성인 공인은 없다.

## 혐오 행동 (`hate-speech`)

보호 특성은 인종, 민족, 국적, 장애, 종교, 계급, 성적 지향, 성별, 성 정체성, 심각한 질병이다. 나이는 다른 보호 특성과 함께 언급될 때 보호되고, 직업은 그때 일부 보호된다. 난민·이주자·이민자·망명 신청자는 가장 극심한 공격(1등급)에서 보호되며, 이민 정책 비판은 허용된다. 개념이나 제도가 아니라 사람을 공격할 때 해당한다. 현지에서 은어로 쓰이는 단어도 해당할 수 있다.

| 점검 | 기본 등급 |
|---|---|
| 보호 특성 집단을 벌레·동물·병균·괴물 등에 빗대기 | 🔴 [규정 명시] |
| 집단 전체를 성범죄자·테러리스트·살인자로 일반화 (폭력·성범죄를 저지른 것으로 설명된 집단, 집단의 과반수 미만을 대표하는 집단은 제외) | 🔴 [규정 명시] |
| 유해 고정관념: 블랙페이스, 홀로코스트 부정, 유대인이 금융·정치·언론을 통제한다는 주장 (예시: 부자 비결 훅에 쓰는 "유대인이 세계 금융을 쥐고 있다") | 🔴 [규정 명시] |
| 병·재해·자살·사망을 집단에게 기원, 혐오 범죄 조롱(실존 인물이 안 나와도), 질병을 앓았다는 이유의 조롱 | 🔴 [규정 명시] |
| 배제·차별 요구: 일반, 정치, 경제(노동 시장 참여 제한), 사회 (예시: "OO 출신은 뽑지 마세요") | 🔴 [규정 명시] |
| 특성에 근거한 모욕: 어리석음, 부정직, 무가치, 추함, 더러움, 토할 것 같다는 표현 | 🔴 [규정 명시] |
| 비방 표현, 특성에 근거해 겨냥한 욕설 (연인과 결별하는 상황의 성별 욕설은 제외) | 🔴 [규정 명시] |
| 성적 지향이나 성 정체성을 바꾸는 제품·서비스 제공 | 🟡 [규정 명시] |
| 보호 특성과 연관된 개념·제도·신념 공격이 즉각적인 상해·위협·차별로 이어질 가능성 | 🟡 [규정 명시] 선거·분쟁 등 긴장 시기, 최근 폭력 기록, 발언자 지위를 본다 |

예외:
- 혐오 발언을 비판하거나 신고하려는 인용, 자기 지칭, 힘을 실어주는 사용은 의도가 분명할 때 허용된다. 불분명하면 삭제될 수 있다.
- 성별로 제한되는 공간 논의와 성전환 권리·이민·동성애의 정치·종교적 논의에는 여지를 둔다. 군대·사법·교직의 성별 제한 찬성도 허용된다.
- 풍자는 위반 요소가 풍자이거나 다른 대상에 귀속되어 그 대상을 모방·비판할 때만 허용될 수 있다. 🟡 [규정 명시]
- 지역: 유럽 사용자는 자국 혐오 발언법을 근거로 법적 삭제 요청을 낼 수 있다.

## 폭력 및 선동 (`violence-incitement`)

| 점검 | 기본 등급 |
|---|---|
| 사망이나 심각한 폭력으로 이어질 수 있는 위협 (모든 사람 대상) | 🔴 [규정 명시] |
| 심각한 부상으로 이어질 수 있는 위협 | 🔴 [규정 명시] 공인과 보호 특성 기반이 아닌 집단은 신빙성이 있을 때만, 그 외 대상은 신빙성과 무관하게 삭제 |
| 낮은 수위의 폭력 위협 | 🔴 [규정 명시] 공인이 아닌 성인(본인 신고 시), 아동, 보호 특성 기반 개인·집단 대상 |
| 심각·중간 정도 폭력을 저질렀다는 자백 (예시: "그때 걔 때려서 병원 보냈다" 무용담). 구조, 정당방위, 접촉 스포츠(중간 이하) 맥락 제외. 납치 위협·묘사 (도움 요청, 정보 제공, 비판, 인지도 제고 제외) | 🔴 [규정 명시] |
| 사람을 해치려는 목적이 명시된 무기 안내(자기방어·무술·군사 훈련 제외), 폭발물 제작·사용 안내(불꽃놀이, 상업용 게임, 낚시 제외) | 🔴 [규정 명시] |
| 파트너 폭력·명예 폭력 찬양, 청부 살인 등 심각한 폭력 서비스 요청·제안, 특정 장소의 무장·강제 침입 위협, 투표·선거 관련 폭력 위협 | 🔴 [규정 명시] |
| 사법 집행관·선거 관리인 위협, 역사적 폭력 사건이나 주소·직장·통근 경로를 언급한 간접 위협 | 🟡 [규정 명시] 대상의 신고, 대상이 어린이 등 맥락 신호와 함께 본다 |
| 과장된 농담 (예시: "이러면 진짜 죽는다") | 🟡 [해석] 문서는 가벼운 표현과 현실성 있는 위협을 언어·맥락으로 구별한다고만 쓴다 |

예외: 인지도 제고·비판 맥락의 위협, 접촉 스포츠의 덜 심각한 위협, 테러리스트 등 폭력 행위자를 향한 특정 위협은 금지하지 않는다. 신체적 상해나 공공 안전 위협이 의심되면 삭제에 더해 계정 비활성화와 사법 공조까지 갈 수 있다.

## 자살 및 자해 (`suicide-self-injury`)

| 점검 | 기본 등급 |
|---|---|
| 자살·자해·섭식 장애를 조장·장려하거나 지침 제공, 이를 조장하는 밈·일러스트 등 허구 콘텐츠 | 🔴 [규정 명시] |
| 사실적 이미지, 자살을 시도했거나 자살로 사망한 사람 묘사, 희생자·생존자 조롱 | 🔴 [규정 명시] |
| 극단적인 체중 감량 행동 방법 (섭식 장애 용어가 없어도 별도 항목) | 🔴 [규정 명시] |
| 섭식 장애 용어 + 인물 이미지, 뼈가 드러난 몸 부위 강조, 제한적 다이어트 방법, 극단적 체중 감량 인정 | 🔴 [규정 명시] |
| 회복 맥락의 치유된 흉터·마른 몸 묘사, 의료 환경의 안락사·조력자살 묘사 | 🟠 [규정 명시] 경고 화면 + 18세 이상 |
| 겪었다고 글이나 말로 인정 (예시: 본인 고백 릴스), 맥락이 모호한 우울·죽음 표현 밈 | 🟠 [규정 명시] 지원 안내 + 18세 이상 |
| 자살·자해·섭식 장애 개념을 조롱·폄하 (예시: 힘든 일을 "자살각"이라고 웃기는 자막), 단순 언급을 넘는 자살 세부 서술 | 🟠 [규정 명시] 18세 이상 |
| 급격한 체중 감량 행위 인정 (예시: "한 달 굶어서 뺐어요" 경험담) | 🟠 [규정 명시] 18세 이상 |
| 자살자의 유서 | 🟡 [규정 명시] 가족·법적 대리인 요청 등으로 식별되면 삭제 가능 |

허용: 경험 공유, 인식 제고, 서로 지지하는 토론, 회복 관련 콘텐츠. 이런 게시물에는 메타가 지원 단체 안내를 띄울 수 있다.

## 폭력적이고 자극적인 내용 (`violent-graphic-content`)

| 점검 | 기본 등급 |
|---|---|
| 비의료 상황 동영상의 사지 절단, 내장 노출, 불타는 사람, 목 베기. 사형 라이브 | 🔴 [규정 명시] |

| 동의 없는 사적 성적 이미지(AI 생성 포함)를 공유·협박·요청, 이를 빌미로 한 금전 강요 | 🔴 [규정 명시] |

| 몰래 찍은 성적 부위 이미지의 조롱·노출 공유, 사적인 성적 대화의 보복·위협성 공유 (예시: 전 연인 대화 캡처 폭로) | 🔴 [규정 명시] |
| 제3자가 공유한, 생존자를 식별할 수 있는 내용 | 🔴 [규정 명시] 생존자 신고 시 |
| 단순 언급을 넘는 비동의 성적 접촉 서사 (생존자 본인, 또는 지지·인식 제고 목적의 제3자) | 🟠 [규정 명시] 경고 화면 |
| 인식 제고 목적이고 자극적이지 않으며 식별 불가, 나체 없음 | 🟡 [규정 명시] 18세 이상 + 경고 레이블 가능 |

허용: 성폭력 문제 토론과 인식 제고, 생존자의 경험 공유.

## 아동 대상 성적 학대, 학대 및 나체 이미지 (`child-sexual-exploitation-abuse-nudity`)

맨 위의 멈춤 규칙을 따른다. 세부 정의는 여기 옮기지 않는다.

근거: 아동 대상 성적 학대 콘텐츠는 단 한 번의 위반으로도 계정이 비활성화될 수 있다 (`enforcement/taking-action/counting-strikes` 페이지) [규정 명시]. 명백한 아동 착취는 NCMEC에 보고된다 [규정 명시]. 아동의 성적 대상화 전반을 같은 위험으로 다루는 것은 이 파일의 점검 원칙이다 [해석].

| 점검 | 기본 등급 |
|---|---|
| 아동 성적 학대의 묘사·찬양·안내·링크, 아동을 대상으로 한 부적절한 접촉·협박. 허구(그림, AI, 가상 인물, 인형) 포함 | 🔴 멈춤 [규정 명시] |
| 실제·허구 아동의 성적 대상화 (이미지와 언어적 묘사 모두) | 🔴 멈춤 [규정 명시] |
| 아동 나체 이미지. 부모가 선의로 올린 자녀 사진도 대부분 삭제 | 🔴 [규정 명시] |
| 성적 요소가 없는 아동 학대를 묘사한 영상·사진 (공유 의도 무관, 예술·만화·영화·게임 이미지 제외), 그 찬양·안내 | 🔴 [규정 명시] |
| 성적 요소 없는 아동 학대 중 메타가 남겨 두는 일부 (당국·안전 파트너 요청 등) | 🟠 [규정 명시] 경고 화면 + 이 페이지 문구로 만 19세 이상 |
| 미성년자 개인을 식별하려는 콘텐츠, 성적 학대 희생자로 추정되는 아동의 식별 정보 | 🟡 [규정 명시] 안전 위험, 당국 요청, 본인·보호자 신고 등으로 삭제 가능 |

계정 신호: 위반 콘텐츠 검색이나 좋아요·저장, 삭제된 그룹 참여만으로도 계정 비활성화나 기능 제한이 가능하다고 적혀 있다.

## 미성년자 추가 보호 (`additional-protection-minors`)

페이지 전체가 요청에 따른 삭제 네 항목이다. 정책 근거 절은 없다.

| 점검 | 기본 등급 |
|---|---|
| 의도하지 않게 유명해진 미성년자를 공격 (예시: 밈이 된 아이를 놀리는 릴스) | 🔴 [규정 명시] 법적 보호자 요청 시 삭제 |
| 성적 요소 없는 아동 학대 이미지(정부 요청 시), 가입 연령 미달 계정(요청 시) | 🔴 [규정 명시] |
| 미성년자 개인을 식별하려는 콘텐츠 | 🟡 [규정 명시] 안전 위험이 있고 사용자, 정부, 사법당국, 외부 전문가의 요청이 있으면 삭제 가능 |

## 인신 착취 (`human-exploitation`)

| 점검 | 기본 등급 |
|---|---|
| 노동 착취(담보 노동 포함), 가정 노예, 강제 범죄를 위한 모집·지원 | 🔴 [규정 명시] |
| 보육원 인신매매와 보육원 자원봉사관광 (예시: 보육원 봉사 여행 모집 릴스) | 🔴 [규정 명시] |
| 제3자의 상업적 성행위 모집·조장, 강제 결혼, 불법 입양, 장기 밀매 | 🔴 [규정 명시] |
| 인신 밀매(불법 입국 주선) 제공·조장·요청 (예시: 브로커 통한 불법 입국 안내) | 🔴 [규정 명시] |
| 노동 착취 위험이 높은 지역의 일자리 제공 (예시: 해외 일자리 모집 릴스) | 🟡 [규정 명시] 사법당국, NGO, 신뢰 파트너의 검증이 있으면 삭제 가능 |

허용: 규탄, 교육, 인식 제고, 뉴스 보도. 개인 안전, 국경 간 이동, 망명 방법에 관한 정보 공유와 요청. 위반 계정과의 상호작용, 위반 콘텐츠 검색, 삭제된 커뮤니티 멤버십으로도 계정이 삭제될 수 있다.

## 창작자가 걸릴 일이 거의 없는 페이지

- **기념 계정 (`memorialization`)**: 사망한 사용자의 계정을 친구·팔로워·가족 요청으로 기념 계정으로 전환하는 절차와, 살인·자살 피해자 계정에서 가족 요청으로 지우는 콘텐츠를 다룬다. 릴스 내용을 점검할 항목은 없다.
- **특정 지역 내 불법 콘텐츠, 제품 또는 서비스 (`locally-illegal-products-services`)**: 당국, NGO, 일반인의 신고와 법원 명령을 처리하는 절차다. 커뮤니티 규정 위반이면 삭제하고, 아니면 법적 검토 후 해당 관할 구역에서만 접근을 제한하며 다른 처벌은 없고 사용자에게 알린다. 금지 품목 목록은 이 페이지에 없다.
- **사용자 요청 (`user-requests`)**: 계정 소유주의 계정 삭제 요청과, 무능력자 계정에 대한 공식 대리인의 삭제 요청을 다룬다. 릴스 내용과 관계없다.

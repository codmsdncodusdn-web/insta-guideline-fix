# 삭제 알림과 계정 문제 대응

콘텐츠 수정이 아니라 이미 받은 제재를 다룰 때 읽는다. 콘텐츠 규정은 [rules.md](rules.md)에 있다.

## 계정 보안 먼저

"계정 정리", "액세스 권한이 없는 동안 계정이 변경되었습니다" 같은 **계정 침해 복구 화면**이 있는지 확인한다. 있으면 규정 진단보다 계정 보안이 먼저다.

- 사용자가 직접 비밀번호를 바꾸고, 2단계 인증을 켜고, 전화번호와 이메일을 확인하고, 계정 센터의 모르는 계정과 의심스러운 타사 앱의 권한을 정리하게 안내한다. 공식 진입점은 `instagram.com/hacked`다.
- "모두 삭제"를 누르기 전에 목록의 항목이 본인 것인지 보게 한다.
- 이 화면이 메일이나 DM의 링크로 열렸다면 피싱일 수 있으니, 거기에 입력하지 말고 앱을 직접 열게 한다.

## 진단

1. 알림 문구와 앱의 **계정 상태** 내용을 받는다. 스스로 확인할 수 없으므로 사용자에게 요청한다. 메타가 밝힌 위반 사유가 원인 추측보다 훨씬 정확하다.
2. 사유를 rules.md의 규정과 연결하고, 해당 콘텐츠의 어느 부분이 걸렸는지 찾는다. 알림에 사유가 없으면 추측임을 밝히고 가능성 순으로 적는다.
3. 다음 행동을 안내한다.
   - 규정에 맞는데 잘못 삭제됐다면: 검토를 요청한다. 복구되면 해당 위반 횟수도 삭제된다. 경로는 프로필 → 메뉴 → 도움말 → 계정 상태 → 삭제된 콘텐츠 → 해당 콘텐츠 → 검토 요청이고, 재검토 사유를 선택해 제출한다. 답변까지 최대 90일이 걸리거나 검토 전에 요청이 종료될 수 있다. 일부 결정은 그 뒤 감독위원회에 재고를 요청할 수 있지만 선정되지 않을 수 있다.
   - 실제로 걸리는 내용이면: 재업로드하지 않고, 같은 패턴의 기존 게시물과 앞으로 올릴 콘텐츠를 고친다.
   - 새 계정을 만들지 않는다.
4. 검토 요청을 돕는다. 공식 안내의 절차는 사유를 고르는 방식이고 자유 입력 칸은 설명되어 있지 않다. 그래서 어떤 사유를 고를지부터 정리하고, 글을 적을 칸이 나올 때를 대비해 짧은 문구를 함께 준다. 사실만 쓰고 없는 사정을 꾸며내지 않는다. 제출은 사용자가 직접 한다. 알림 문구를 아직 못 받았으면 대괄호 칸을 두고 문구를 함께 요청한다.

사용자가 짐작하는 원인과 알림의 사유가 다르면 알림을 따른다. "스팸" 알림인데 제목의 돈 단어를 탓한다면, 단어만 바꿔도 진짜 원인은 남는다고 알려준다.

## 결과 형식

우회 요청이 섞여 있으면 거절과 이유를 맨 앞에 쓴다.

```markdown
(우회 요청이 있었다면) 도울 수 없는 것과 이유
## 계정 보안: 침해 복구 화면이 있을 때만
## 원인: 알림 사유에 맞는 규정, 걸린 부분. 추측이면 추측이라고 밝힌다
## 먼저 보내주세요: 빠진 알림 문구, 계정 상태, 원본
## 다음 할 일: 검토 요청 또는 수정. 문구를 요청받았으면 주장을 바꾼 새 콘텐츠의 방향
## 검토 요청: 고를 사유와 문구
## 못 본 것: 확인하지 못한 항목
```

## 알림 문구 → 규정

| 알림 문구 | 규정 |
|---|---|
| 참여, 계정, 관리자 역할 또는 페이지 등을 구매·판매하는 것 같음 | 스팸: 참여·자산의 판매, 구매, 교환 |

새 문구를 받으면 이 표에 추가한다.

## 계정 규정 (`account-integrity`, `inauthentic-behavior`, `authentic-identity-representation`)

| 점검 | 기본 등급 |
|---|---|
| 비활성화된 계정과 소유자가 같은 계정, 삭제를 피하려고 만들거나 용도를 바꾼 계정 | 🔴 [규정 명시] |
| 규정 시행이나 검토를 피하려고 계정을 쓰는 것 | 🔴 [규정 명시] |
| 시행을 피하려는 허위 계정, 신고 시스템 악용 | 🔴 [규정 명시] |
| 해킹당한 계정 | 🟡 [규정 명시] 소유권 확인을 요청받을 수 있음 |
| 스크립트 등 자동화로 계정을 이용 (승인된 경로 제외) | 🟡 [규정 명시] 소유권·활동 확인을 요청받을 수 있음 |
| 남의 이미지·이름으로 속이기, 허가 없이 대변 | 🔴 [규정 명시] |
| 팬·패러디 계정인데 비공식임을 계정 이름에 쓰지 않음 | 🟠 [규정 명시] |
| 추천하지 않으려는 내용을 프로필에 반복 게시, 좋아요 구매 | 🟠 [규정 명시] 계정 추천 제외 |

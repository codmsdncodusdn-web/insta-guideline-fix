# insta-guideline-fix

릴스 스크립트, 영상, 카드뉴스를 메타 커뮤니티 규정과 인스타그램 추천 가이드라인에 맞게 고쳐 주는 Claude 스킬입니다. 문제 되는 문구를 근거와 함께 짚고, 수정 전후 표와 그대로 쓸 수 있는 수정본을 줍니다.

## 이런 일을 합니다

- 삭제되거나 도달이 막힐 수 있는 문구와 장면 찾기
- 수정 전후 표와 수정본 전체 제시
- 돈 약속을 뺀 뒤에도 원문의 뉘앙스를 살린 훅 후보 제시
- 근거를 규정 명시, 해석, 경험으로 구분해 표시
- 삭제 알림을 받았을 때 원인 정리와 검토 요청 안내

초성이나 특수문자로 표현을 숨기기, 제목만 바꾼 재업로드, 제재를 피하기 위한 새 계정처럼 규정을 회피하는 수정은 돕지 않습니다.

## 설치

Claude Code의 개인 스킬 폴더에 내려받습니다.

```bash
git clone https://github.com/codmsdncodusdn-web/insta-guideline-fix.git ~/.claude/skills/insta-guideline-fix
```

금전 표현 스캐너를 쓰려면 [Node.js](https://nodejs.org/)가, 영상 프레임을 보려면 [FFmpeg](https://ffmpeg.org/)가 필요합니다.

## 사용법

```text
/insta-guideline-fix

(릴스 스크립트나 카드뉴스 문구 붙여넣기, 또는 이미지·영상 파일 경로)
```

"이 카드뉴스 가이드라인에 맞게 고쳐줘"처럼 말해도 실행됩니다.

## 알아두실 점

- 메타 공식 도구가 아니며 메타와 관련이 없습니다.
- 위험을 줄이는 도구입니다. 메타는 판단 기준을 전부 공개하지 않으므로, 수정본도 삭제되지 않는다고 보장하지 않습니다.
- 규정 요약은 2026년 11월 3일 기준이며 자동으로 갱신되지 않습니다. 판단이 갈리면 [메타 커뮤니티 규정 원문](https://transparency.meta.com/policies/community-standards/)을 확인하세요.
- 법률 자문이 아닙니다. 광고 규정, 서비스 약관, 파트너 수익화 정책, 청소년 콘텐츠 가이드라인은 포함하지 않았습니다.
